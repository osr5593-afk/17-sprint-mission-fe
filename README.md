# 판다마켓

- 프로젝트 목적: 중고거래 사이트

## 소개

안녕하세요! 판다마켓에 오신 것을 환영합니다!
판다마켓은 중고거래 커큐니티 플랫폼입니다. 여러분들의 소중한 물건들을 자유롭게 올리고 판매도 하고 다른 사용자의 물건도 구경해 보세요.

## 기술 스택

- HTML
- CSS

- [ ] 로그인 페이지
- [ ] 회원가입 페이지

- [ ] 소셜미디어 링크
